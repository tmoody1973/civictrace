## 4. Hard-won gotchas (do NOT relearn)

- **`pnpm e2e` reuses whatever owns port 3000.** Tarik's dev server runs there in CLOUD
  mode. Kill it before e2e, restart `pnpm dev` after — otherwise e2e talks to the real
  cloud (this bit us before; playwright.config pins env only for servers IT starts).
- **`.gcloudignore` exists, so `.gitignore` is NOT consulted by gcloud builds.** Media
  exclusions are in it now; check it before adding big files anywhere.
- **Vertex 429 RESOURCE_EXHAUSTED happens on `global` Gemini Flash.** Cloud Tasks retry
  heals it (proven twice). A FAILED publish step usually just needs the ordered publisher
  re-run — already-terminal jobs skip; only SUCCEEDED is terminal in the worker job repo.
- **Cloud Tasks burns task names ~1h.** Intake create-case task name is `create-{bundle_id}`;
  for a re-run within the hour, POST the worker endpoint directly instead.
- **pypdf paraphrase trap:** models reword table quotes; the quote gate rejects, and the
  workflow now feeds the reasons back for ONE corrected attempt
  (`test_workflow_extraction_retry.py`). Never widen this into a loop.
- **The entity gate is in CODE** (`sanitize_entity_links` in `app/services/validator.py`):
  CONFIRMED requires a candidate's exact identifier string literally in the evidence text;
  over-claims are demoted, invented ids dropped. Candidates come only from
  `entity_registry.py` (all known manifests). Fake/CI mode passes empty candidates → no-op.
- **Media artifacts are never re-fetched or served inline** (Granicus 403s datacenter IPs;
  API returns 413 for video/audio or >64MB). The transcript is the readable record;
  playback is MOO-725 via short-lived signed URLs.
- **Intake formats:** PDFs only, enforced by byte check; the screen labels Word files
  unselectable. Data: 76% of recent Milwaukee attachments are PDF, 4% Word. When formats
  expand (726), the no-silent-holes rule applies: excluded documents must be visibly
  listed on the case.
- **STT diarization exists in exactly one pair:** chirp_3 + `us` multiregion; no per-word
  confidence (UI keys on null). Frontend e2e axe rule `aria-valid-attr-value` on the
  approval drawer is known-flaky; the color-contrast findings were real and are fixed.
- Piping to `tail`/`grep` eats exit codes; check the real command's `$?`.
